# 🌤️ Emotional Weather

A gentle household mood-sharing app. Family members set their emotional weather — visible to everyone at a glance. Passive ambient awareness, not therapy.

## Weather States
⛈️ Stormy · 🌧️ Rainy · ☁️ Cloudy · ⛅ Partly Cloudy · 🌤️ Mostly Sunny · ☀️ Sunny · 🌈 Rainbow

## Features
- **Household setup** with emoji avatars
- **Beautiful weather cards** with CSS-only animations
- **Dashboard** showing everyone's current weather
- **30-day history** heatmap
- **Gentle nudges** when someone's been stormy for 2+ days
- localStorage-based, works offline

## Dev
```bash
npm install
npm run dev
```

Built with React 19 + Vite + TypeScript + Tailwind CSS.
